# Collection Timeline / 收录时间线

[English](#english) | [简体中文](#简体中文) · [Documentation index / 文档索引](../docs/README.md)

## English

This timeline groups projects by the month they were formally accepted into Awesome AI Hardware, newest first. It provides a browsable record of what was added and why it is relevant.

An entry may include:

- a concise description of the AI and hardware interaction;
- the source GitHub repository;
- the original X post or announcement;
- original images, videos, demos, articles, or documentation;
- the category, license, acceptance date, and last verification date.

The acceptance date is distinct from the publication date, repository creation date, and discovery date. Media is linked from its original source; unlicensed third-party media is not copied into this repository.

## 简体中文

本时间线按照项目被 Awesome AI Hardware **正式批准收录的月份**倒序整理，方便用户直接浏览新增资源以及它们值得关注的原因。

每个条目可以包含：

- AI 与硬件如何交互的简短介绍；
- GitHub 源代码仓库；
- 原始 X Post 或发布页面；
- 原始图片、视频、Demo、文章或文档；
- 分类、许可证、收录日期与最近核验日期。

收录日期与项目发布日期、仓库创建日期、发现日期相互独立。媒体资源链接到原始来源，不在本仓库复制没有授权的第三方素材。
