# Extended X Showcase Batch / 扩展 X Showcase 批次

**Reviewed / 审核日期：** 2026-08-02 · [Review archive / 审核记录首页](README.md)

## English

Fifteen submitted X post URLs were inspected at the post level and cross-checked against their linked repositories. Thirteen primary showcase records were created; the older OpenArm post and the later reBot-DevArm post are preserved as related URLs instead of duplicate entries.

### Formal catalog additions

| Project | Decision | Evidence |
|---|---|---|
| LightMem-Ego | Listed | MIT license; Rokid AI Glass Android client; camera/audio streaming; LLM, embedding, and hierarchical-memory backend. |
| OpenArm | Listed | Apache-2.0 project index with documented component licenses; open hardware, control, teleoperation, datasets, simulation, training, and inference stack. |
| reBot-DevArm | Listed | CERN-OHL-W-2.0 hardware source; STEP/BOM/assembly material plus LeRobot, Isaac Sim, ROS, and visual-grasping integrations. |

### Showcase-only or deferred

| Candidate | Decision | Reason |
|---|---|---|
| SABR | Showcase only | Strong build documentation, but the current implementation is classical sensor fusion and PID control rather than AI. |
| ESP32 AI post | Existing project | Added the verified X demo to the already listed ESP32 AI project. |
| KittenTTS | Showcase only | Licensed lightweight edge model, but the repository does not yet provide a concrete hardware integration build. |
| DroneBridge ESP32 | Showcase only | Useful robotics and IoT infrastructure, but the implementation contains no AI component. |
| OpenQuadruped | Showcase only | Hardware and classical control are implemented; reinforcement learning is still a roadmap item. |
| Weekend Gemini Robotics lab | Showcase only | Valuable live demo, but no implementation repository was linked. |
| OpenGlasses | Deferred | Direct AI-wearable design, but the repository has no license. |
| Mentra smart glasses | Showcase only | Product and SDK demonstration without a linked complete open hardware repository. |
| OmiGlass + fNIRS | Existing project | Preserved as a showcase linked to the already listed Omi repository. |
| Gemma smart-glasses demo | Showcase only | Relevant hackathon video, but no source repository was linked. |

## 简体中文

本批次逐帖检查了 15 个 X Post URL，并与关联 GitHub 仓库交叉核验。最终建立 13 条主要 Showcase 记录；较早的 OpenArm 帖子和较晚的 reBot-DevArm 补充帖作为关联 URL 保存，避免重复条目。

### 正式目录新增

| 项目 | 结论 | 依据 |
|---|---|---|
| LightMem-Ego | 收录 | MIT 许可证；包含 Rokid AI 眼镜 Android 客户端、摄像头与音频流、LLM、向量嵌入和分层记忆后端。 |
| OpenArm | 收录 | 项目索引采用 Apache-2.0，各组件许可证有明确记录；覆盖开放硬件、控制、遥操作、数据集、仿真、训练和推理。 |
| reBot-DevArm | 收录 | 硬件源文件采用 CERN-OHL-W-2.0；包含 STEP、BOM、装配资料以及 LeRobot、Isaac Sim、ROS 和视觉抓取集成。 |

| 候选 | 结论 | 原因 |
