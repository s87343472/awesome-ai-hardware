# X Showcase Batch / X Showcase 批次审核

**Review date / 审核日期:** 2026-08-01

## English

Eleven supplied X posts were opened and checked for visible post text, author, publication date, media type, external links, and linked repositories. Repository metadata, license, source layout, and documentation were then verified separately through GitHub.

### Catalog changes

| Project | Decision |
|---|---|
| [Anima](https://github.com/Fullive-AI/Anima) | Listed: Apache-2.0 local agent OS with a LangGraph brain, memory, device skills, tests, documentation, and Mi Home adapters. |
| [Autonomous Computer](https://github.com/autonomous-ai/autonomous-computer) | Listed: MIT-licensed open hardware build guides with BOMs, CAD, assembly material, BIOS settings, and multi-GPU local-AI configurations. |
| [Cyclo Intelligence](https://github.com/ROBOTIS-GIT/cyclo_intelligence) | Listed: Apache-2.0 physical-AI platform for ROBOTIS AI Worker data collection, policy training, inference, and robot execution. |
| [Party OS](https://github.com/Roboparty/Party_OS) | Showcase only: the submitted repository is a GPL-3.0 umbrella roadmap that links several separately licensed implementation repositories. Review those subprojects individually before formal listing. |
| Blueprint | Showcase only: the post demonstrates a hardware-design product, but no open-source repository is linked. |

PicoLM, Omi, Home Generative Agent, and mcp2mqtt were already listed and now link to their verified community showcase posts. Codex Light and Buddie remain deferred because their repositories still lack explicit licenses.

### Provenance and media corrections

- Codex Light was posted by the implementation's creator.
- ROBOTIS AI Worker was posted by an engineer presenting the team's own work.
- Autonomous Computer was posted as the project team's own GitHub and build-guide thread.
- The remaining posts are community explanations or recommendations, not treated as original author statements.
- The PicoLM post contains image media rather than a video.
- The supplied Autonomous Computer URL is the build-guide reply; its video is in the preceding post of the same thread.
