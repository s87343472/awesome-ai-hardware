## Findphone Claude-assisted Bluetooth finder / Findphone：Claude 协助制作的蓝牙寻机工具

**Published / 发布：** 2026-08-05 · **By / 发布者：** Ben Zhang · **Relationship / 关系：** Author / 作者 · **Media / 媒体：** Video / 视频 · **Catalog / 目录：** Showcase only / 仅 Showcase

The creator asked Claude how to find an MDM-disabled phone, then used the generated macOS Bluetooth RSSI meter to walk toward the stronger signal and recover it. The released utility has no runtime AI component and the repository has no license, so it is preserved as a build-story showcase rather than a catalog project.

作者在手机受 MDM 限制、无法使用 Find My 时向 Claude 求助，再用生成的 macOS 蓝牙 RSSI 仪表沿着增强的信号找回手机。已发布工具运行时不含 AI 组件，且仓库没有许可证，因此保留为制作故事 Showcase，而非正式项目目录。
